# Q1 — Incident count calculation

Before running the test on November 24, 2026, Copilot predicted that a list with
two open incidents, one in progress, one resolved, one closed, and one
archived open incident would produce **5 visible incidents and 3 active
incidents**. The archived incident should not be counted; active means open
or in progress. An empty list should produce zero for both counts.

The test returned 5 visible and 3 active, and zero for the empty list.
`npm run test:all` also passed afterward. This prediction was generated by
Copilot, not independently supplied by me.

For a separate case, before it was added or run, I predicted **6 visible and
4 active incidents** from two open, two in progress, two resolved, and one
archived open incident. Active means open or in progress, and archived
incidents are excluded.

The focused test passed with the predicted result.
