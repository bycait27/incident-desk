## Prediction before the 2026-11-24 check

The `MigrationReversibilityTest` will exit successfully. In a temporary
PostgreSQL schema, migrations V1–V5 will apply, the V5 index and its history
entry will be rolled back without removing the stored synthetic incident, and

## Procedure

Start the local PostgreSQL container as described in the
[README](../../README.md), then run from the repository root:

```powershell
mvn -f backend/pom.xml "-Dtest=MigrationReversibilityTest" test
```
