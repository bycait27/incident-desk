# F1 — React and TypeScript incident board

## Claim

The public incident board is implemented in React and TypeScript. It loads incidents, searches titles and descriptions, and filters by status and severity. The frontend TypeScript project enables `strict`; its source contains no explicit `any` or `@ts-ignore`.

## Reproduce

From a clean checkout:

```powershell
cd frontend
npm ci
npm run typecheck
npm run lint
npm run build
```

The type-check command is `tsc --strict --noEmit -p tsconfig.app.json`. GitHub Actions runs the same type-check, lint, and production build on pushes to `main`/`develop` and pull requests targeting `main`.

A type-check exit code of `0` with no TypeScript diagnostics demonstrates that the strict frontend project type-checks. The production build independently confirms that Vite can bundle the page. The search and filter behavior is implemented in `frontend/src/App.tsx`.

The compiler alone does not reject every explicit `any`; check the source separately:

```powershell
rg -n ':\s*any\b|@ts-ignore' src
```

No matches are expected (ripgrep exits with code `1` when there are no matches).
