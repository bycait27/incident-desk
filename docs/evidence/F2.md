# F2 — Remote loading, empty, and error states

## Claim

The interface implements visible progress and failure states for remote
operations. The evidence below covers the public incident list and external
monitor panel; it does not yet demonstrate every remote operation.

## Reproduce

From a clean checkout:

```powershell
cd frontend
npm ci
npm run test
npm run typecheck
npm run lint
npm run build
```

## Interpretation and limits

The public board remains usable without signing in. Signed-in viewers can submit incidents for private IT review; only operators see the pending queue and can publish, edit, or archive entries. Submission/update errors are shown in the associated form, and successful actions have visible status messages.

My screenshots don't prove all remote calls. Authentication-status errors
and submit, update, publish, archive, and logout failure paths still need
verification; do not mark F2 complete on this evidence alone.
